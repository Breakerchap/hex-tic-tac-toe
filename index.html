HeXO

Connect 6 in a straight line by default. The first move must be at the origin, then every placement must stay within 11 spaces of an existing tile. The starting player uses the first-turn placement setting, then normal turns use the current placements-per-turn setting.

Game rules
Default move order
Guide: x = P1, o = P2, % = P3, & = P4.
Turns: The label before `:` is whose turn it is, and x/o/%/& actions choose whose stone gets placed, so `x: o` means Player 1 places Player 2's stone.
Actions: x/o/%/& = stone, d = duck, k/kd = king duck, e = echo, r = Rift Bloom, p = pig.
Repeats: 3(...) = finite repeat, inf(...) or ∞(...) = repeating tail.
Note: Powder Cascade, Bed Siege, and Foundry War ignore move order.
No custom win conditions.

Rules & controls
  • Click a board space to place.
  • The first move must be at (0, 0).
  • Later placements must be within 11 spaces of an existing board space.
  • Drag with right mouse button or middle mouse to pan.
  • Scroll to zoom.
  • Winning line length uses the current in-a-row setting.
  • The opening turn uses the current first-turn placement setting.
